Взаимодействия и разнесение по времени

С лекарствами

  • Омега‑3 + антикоагулянты/антиагреганты: возможна аддитивность. Обсудить с врачом.
  • Магний/Кальций/Железо + антибиотики (тетрациклины, фторхинолоны): снижает всасывание — разнести ≥4 часа.
  • Мелатонин + седативные/антигипертензивные: усиление эффекта — осторожно.
  • Ашваганда + тиреоидные препараты: возможная модуляция функции щитовидной железы — контроль у врача.

Между добавками

  • Кофеин + L‑теанин: синергия — более ровный фокус, меньше «дрожи».
  • Магний + Теанин/Глицин/Таурин: аддитивное расслабление — учитывайте сонливость.
  • Кальций + Железо/Цинк: конкуренция за всасывание — разнести на 2–3 часа.
  • Витамин D3 + К2: совместимость при поддержке кальциевого баланса.

Общие правила разнесения

  • Минералы (магний, кальций, железо, цинк) — разносите между собой и с лекарствами.
  • Жирорастворимые (D3, K2, омега‑3) — с едой, где есть жир.
  • Стимуляторы (кофеин) — не поздно днём, чтобы не портить сон.

Когда остановиться

  • Новые выраженные симптомы после начала приёма.
  • Сложные схемы с несколькими лекарствами — обсудить с врачом.

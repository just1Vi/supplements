# БАД‑гид (GitHub Pages)

Статический сайт расположен в каталоге `docs/` и готов к публикации через GitHub Pages (Project Pages).

Как опубликовать:

1. Создайте репозиторий и добавьте код:
   - `docs/` — корень сайта (включая `.nojekyll`)
2. В настройках репозитория:
   - Settings → Pages → Source: `Deploy from a branch`
   - Branch: `main` (или ваш основной) → Folder: `/docs`
3. Сохраните. Через пару минут сайт будет доступен по адресу GitHub Pages репозитория.

Локальный предпросмотр:

- Любой статический сервер, например:
  - Python: `python3 -m http.server 8888 --directory docs`

Кастомный домен (опционально):

- Добавьте файл `docs/CNAME` с вашим доменом (одна строка), укажите его в Settings → Pages → Custom domain и настройте DNS (CNAME на `<user>.github.io`).

Примечания:

- Файл `.nojekyll` отключает обработку Jekyll и позволяет отдавать статические ресурсы «как есть».
- Если нужен корневой путь не `/`, используйте относительные ссылки (уже настроено) — сайт работает из любой поддиректории.
